 Python Class 3 - Loop Quest

   About This Assignment

This repository contains my **Python Class 3 - Loop Quest Assignment**.

In this assignment, I practiced Python loops, conditions, filtering data, and basic data processing through 5 beginner-friendly programming missions.

##  Missions Included

### 1. Robot Steps 
A program that asks the user for the number of steps and prints each step using a `for` loop.

### 2. Secret Number Scanner 
A program that scans numbers from 1 to 30 and prints only the even numbers greater than 10.

### 3. Power Up Pattern 
A program that asks for a base number and the number of multiples, then generates the required pattern using a loop.

### 4. Score Filter 
A program that checks a list of student scores and prints scores that are 70 or above.

### 5. Mini Data Analyzer 
A program that processes temperature data using loops and identifies temperatures of 35 or above, counts matching days, and counts days below 30.

##   Concepts Practiced

- `for` loops
- `range()`
- `if` conditions
- Comparison operators
- Logical operators
- Modulus `%`
- Lists
- Filtering data
- Counting values
- Basic data processing
- User input
